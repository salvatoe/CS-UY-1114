## Purpose of This Companion

This project is designed for students who want:

* Additional explanations beyond lecture slides
* Extra practice questions
* Clear and simplified notes
* Rewritten examples with detailed comments
* A way to review for lab exams, midterms, and the final
* A beginner-friendly learning path through the course material

The notes emphasize clarity, step-by-step reasoning, and common mistakes, making them ideal for students with little or no prior programming experience.

* CS-UY 1134 (Data Structures)

* Basic technical interview preparation
